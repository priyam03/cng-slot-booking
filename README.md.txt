# CNG Slot Booking System

A scalable web application for booking CNG filling slots online.

## Problem Statement

Long queues at CNG stations cause:

- Traffic congestion
- Fuel wastage
- Time loss

This application allows users to:

- Register themselves
- Register their vehicles
- Find nearby CNG pumps
- Book available slots
- Receive QR-based booking confirmation
